# Publicação inicial proposta — aguarda sua autorização

Manifesto SHA-256: `4c64c2f408ad4bdd3f1e76c8dd35e12eec4d23a6ed4c2cf6e9a85d663e0bb02b`.

Somente estas três orientações conservadoras seriam publicadas para atendimento assistido. As outras 77 regras ficam sem publicação; as 16 pendentes não são promovidas.

**AUTHORITY** — escopo: *

Posso orientar e registrar o pedido. A autorização, a conferência dos documentos e a confirmação do serviço cabem à Administração.

**LOCATOR** — escopo: LOCALIZACAO

Posso reunir as referências para localizar o sepultamento ou ossuário. Não vou indicar uma localização sem confirmação no cadastro.

**FOLLOWUP_SCOPE** — escopo: CO09

Posso consultar o andamento pelo protocolo informado neste atendimento ou registrar uma consulta para a equipe localizar a solicitação. Não vou presumir aprovação por uma declaração ou pagamento.
